# A Bela Dama

Arquivo digital de Elysana Kesler: história, família, habilidades, formas e biblioteca.

## Desenvolvimento

```bash
npm run install:ci
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
```

O projeto usa Next.js/Vinext e foi preparado para publicação no Vercel ou OpenAI Sites. A persistência compartilhada será conectada ao Supabase quando o banco correto estiver disponível.
